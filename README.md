# Modi — გადახდის გვერდი

ეს არის GitHub Pages-ზე გასაშვები, მობილურზე მორგებული საბანკო რეკვიზიტების გვერდი.

## მიმღებების და IBAN-ების შეცვლა

`index.html` ფაილის ბოლოში მოძებნეთ `const ACCOUNTS`:

```js
const ACCOUNTS = {
  bog: { recipient: "გულია ნადირაშვილი", iban: "" },
  tbc: { recipient: "", iban: "" }
};
```

ორივე ბანკისთვის მიუთითეთ შესაბამისი მიმღები და IBAN. თუ საქართველოს ბანკის მიმღები სხვაა, შეცვალეთ ისიც. გვერდზე მონაცემები ავტომატურად შეიცვლება ბანკის არჩევისას. ცარიელი ან არასწორი IBAN-ის შემთხვევაში კოპირება გამორთულია.

## GitHub Pages

ახალ საჯარო repository-ში ატვირთეთ `index.html` ფაილი (არა ZIP). Settings → Pages → Deploy from a branch → main → /(root) → Save.

**შენიშვნა:** ეს გვერდი გადახდას არ ადასტურებს; ჩარიცხვა გადაამოწმეთ ბანკში.
